# Dead or Alive 6 Motion / Pose Editor (Cheat Engine)

基于 Cheat Engine 7.5 制作的 **DEAD OR ALIVE 6** 角色姿态摆放修改器，带可视化人体关节交互面板，支持**头部/面部/头发同步**以及**布料物理与碰撞体实时联动**。

## 功能特点

- **物理 / 布料 / 碰撞联动**：在骨架解算上游的部位分发入口（`DOA6_UpdateParts`，AOB 特征定位，无需扫描与断点）注入修改局部骨骼变换，自动驱动蒙皮、布料物理与碰撞体跟随。
- **头 / 脸 / 头发同步**：实时合成躯干→颈部链（`0 → 1 → 2 → 9 → 10 → 11`）并同步头部（`12`）到面部骨架与头发骨架，冻结或转动腰/胸/颈/头时不再脱节。
- **可视化人体关节面板**：
  - 左侧正面人体骨骼图：**左键点击关节**直接选中，**右键点击关节**一键归零；橙色为当前选中、绿色为已修改关节。
  - 支持 P1 / P2 独立编辑、自动识别角色骨架（换人或重开训练模式自动重新锁定）。
  - 旋转采用**指数映射（旋转向量）**，彻底避免 `Y = ±90°` 时的欧拉角万向节死锁；支持 `-15° / -5° / +5° / +15°` 快捷微调与三轴平移（cm）。
  - 支持**左右对称镜像复制**、**P1 ↔ P2 姿势复制**、以及 `.pose` 姿态文件保存与加载。

## 使用方法

1. 启动 **DEAD OR ALIVE 6**，进入训练模式、对战或衣柜让角色出场。
2. 打开 **Cheat Engine 7.5**，附加到 `DOA6.exe`。
3. 打开本仓库中的 `doa6_pose.CT`，弹窗提示是否执行表内 Lua 脚本时点击 **Yes**。
4. 勾选 **`1. 启用 DOA6 姿态修改器（勾选后自动弹出面板）`**，约 0.3 秒后自动弹出置顶编辑面板。
5. 勾选 **`冻结动画 (F8)`**，在左侧人体图上点击任意关节，拖动右侧滑条即可自由摆姿势。

## 快捷键

| 快捷键 | 功能 |
|---|---|
| `F6` | 显示 / 隐藏姿态编辑面板 |
| `F8` | 切换当前角色的动画冻结状态 |
| `F9` | 按当前画面重新抓取一帧冻结 |

## 常用身体骨骼编号

| 编号 | 部位 | 编号 | 部位 |
|---|---|---|---|
| `1` | 整体位置 / 高度 (Root) | `2` | 骨盆 / 全身旋转 (Pelvis) |
| `9` | 腰部 (Waist) | `10` | 胸部 (Chest) |
| `11` | 颈部 (Neck) | `12` | 头部 (Head) |
| `13 / 14` | 左 / 右锁骨 | `15 / 16` | 左 / 右上臂 |
| `17 / 18` | 左 / 右前臂 (肘) | `19 / 20` | 左 / 右手腕 |
| `3 / 4` | 左 / 右大腿 (髋) | `5 / 6` | 左 / 右小腿 (膝) |
| `7 / 8` | 左 / 右脚踝 | `23 / 24` | 左 / 右脚趾 |
| `26..43` | 左 / 右手指主关节 | `0..255` | 面板支持手动输入任意骨骼号 |

## 注意事项

- 仅作用于本地客户端，请仅在单人训练、本地模式或摄影/摆拍场景下使用，切勿在联网对战中启用。
- 退出游戏前建议先取消勾选主开关以还原原始指令。
